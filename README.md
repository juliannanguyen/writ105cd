# WRIT 105CD - Writing with Code

A collection of projects created for WRIT 105CD

## Projects

### Museum Day
An interactive fiction game created in Twine. Users can choose which exhibits in a fictional museum to explore and decide whether to admire, touch, or steal artwork. If you choose to steal, you're presented a series of choices that lead to escape or capture. 

[Download here](https://github.com/juliannanguyen/writ105cd/blob/b48fdb77c9b32e0e3801099526ff7115cae2630f/museum-day/Museum%20Day.html)


### Final Project: Overworked
An interactive narrative game created in Twine that places they player in the role of a college student juggling the academic responsibilities of the quarter system, work hours, social pressures, and personal well-being.

[Download here](https://github.com/juliannanguyen/writ105cd/blob/a6a59cf00351d3d090088af69b09a74b6966d3c9/final-project/Overworked.html)


### Multimodal Group Project
A text-based selection game developed in Twine that allows players to select different budegets and markets. Each market has different prices and players are allowed to choose different ingredients. The game was created to address the difficulties college students face living on their own and cooking for the first time.

[Download here](https://github.com/juliannanguyen/writ105cd/blob/7257d88e336c223afb4508287b19cf62af29f03e/multimodal-project/cookyourroute%20-1.html)
