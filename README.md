# WRIT 105CD - Writing with Code

A collection of projects created for WRIT 105CD

## Projects

### Museum Day
An interactive fiction game created in Twine. Users can choose which exhibits in a fictional museum to explore and decide whether to admire, touch, or steal artwork. If you choose to steal, you're presented a series of choices that lead to escape or capture. 

[Play it here](https://github.com/juliannanguyen/writ105cd/blob/c9fc0f213f515250b8291acc15fcbd1148ddc819/museum-day/Museum%20Day.html)
